# jena, software developer portfolio .ᐟ.ᐟ

An interactive portfolio showcasing my software engineering projects, design work, technical experience, and professional journey. Inspired by Sydney trains, postcards, and travel keepsakes, the site combines playful interactions with responsive design and modern web technologies.

**.✦ ݁˖ Live Website: https://jenabathan.com/**

### Technology

* React 19
* Vite
* Tailwind CSS v4
* Framer Motion
* GSAP
* Lenis

### Features

* Animated train-door landing experience
* Interactive project postcards
* Draggable technology display
* Passport-inspired milestone timeline
* Responsive layouts and accessible interactions

### Getting Started

```git clone https://github.com/jena-mari/portfoliojenabathan.git
cd portfoliojenabathan
npm install
npm run dev
```

To create a production build:

```npm run build```
